n0 = tc = calculated time complexity

n1 = sval = start value of tracked variable
n2 = cond = conditional
n3 = add = addition/subtraction operations on tracked variable
n4 = mult = multiplication/division operations on tracked variable
n5 = exp = exponents on tracked variable
n6 = addrec = addition/subtraction inside recursive call
n7 = multrec = multiplication/division inside recursive call
n8 = numrec = number of recursive calls
